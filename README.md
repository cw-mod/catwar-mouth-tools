# CatWar: инструменты для рта

Набор инструментов для предметов во рту на игровой странице `/cw3` на **catwar.su** и **catwar.net**: чердак, закрепление типов, сортировка и быстрое выделение для смешивания.

> **v2.0.0** — мод переработан: плавающее окно «Рецепт» и сам рецепт убраны, сортировка переехала в блок рта, добавлены закрепление типов 🔒 и инструменты смешивания (влиты из отдельного мода mix-select — он больше не нужен).

- Страница мода: https://cw-mod.github.io/catwar-mouth-tools/

## Установка (Tampermonkey)

1. Установите [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте [mouth-tools.user.js](https://cw-mod.github.io/catwar-mouth-tools/mouth-tools.user.js) и подтвердите установку.
3. Зайдите на `https://catwar.su/cw3` или `https://catwar.net/cw3`.
4. Если стоял отдельный мод «быстрое выделение для смешивания» (mix-select) — удалите его, теперь всё здесь.

## Что умеет

- **Чердак** — ненужные типы предметов отдельным сворачиваемым блоком вверху рта. `Shift`+клик по предмету — на чердак / обратно.
- **Закрепление 🔒** — закреплённый тип (`Alt`+клик по предмету — закрепить/открепить):
  - не выделяется Ctrl+кликом и «Выбрать всё»;
  - не попадает в «✚ Всё» для смешивания — случайное смешивание исключено;
  - помечается замочком на предметах и счётчиком 🔒 в панели рта.
- **Сортировка** — «как у игры / по типу» селектом прямо в блоке рта (плавающего окна больше нет).
- **Быстрое выделение** — `Ctrl`+клик (`⌘` на Mac) по предмету выделяет весь тип; работает и в режиме смешивания.
- **Кнопки смешивания** — прилипающая панель у списка рта:
  - «✚ Всё» — войти в режим смешивания и выделить все предметы (кроме 🔒 и заблокированных);
  - «→ В смешение» — войти в режим смешивания, сохранив текущее выделение (после Ctrl+кликов);
  - «✖ Снять» — снять выделение.

Само смешивание скрипт не подтверждает — после выделения игрок сам нажимает игровую кнопку «Смешать».

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Выделить/снять весь тип предмета | `Ctrl`+клик (`⌘` на Mac) |
| На чердак / обратно | `Shift`+клик |
| 🔒 Закрепить/открепить тип | `Alt`+клик |

Подсказка про горячие клавиши всегда видна в панели инструментов рта.

## Миграция с v1.x

Чердак, свёрнутость и сортировка «по типу» сохраняются. Рецепт, позиция и размер плавающего окна больше не используются; сортировка «по рецепту» сбрасывается на «как у игры».
