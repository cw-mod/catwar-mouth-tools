CatWar: инструменты для рта

Набор инструментов для предметов во рту на catwar.su и catwar.net: чердак, закрепление типов, сортировка и быстрое выделение для смешивания — без отдельных окон.

Скачать юзерскрипт

Версия 2.0.0 (бывший «Рецепт»: окно рецепта убрано, функции смешивания влиты из мода mix-select). Юзерскрипт для Tampermonkey. Автообновление: mouth-tools.meta.js.

Установка

  1. Установите Tampermonkey.
  2. Нажмите «Скачать юзерскрипт» — Tampermonkey предложит установку.
  3. Откройте игровую https://catwar.su/cw3 или https://catwar.net/cw3.
  4. Если стоял отдельный мод «быстрое выделение для смешивания» (mix-select) — удалите его, теперь всё здесь.

Что умеет

  • Чердак — ненужные типы предметов отдельным сворачиваемым блоком вверху рта (Shift+клик по предмету — на чердак / обратно).
  • Закрепление 🔒 — закреплённый тип не выделяется «быстрым выделением» и «Выбрать всё» и не попадает в смешивание случайно (Alt+клик по предмету — закрепить/открепить).
  • Сортировка — «как у игры / по типу» селектом прямо в блоке рта.
  • Быстрое выделение — Ctrl+клик (⌘ на Mac) по предмету выделяет весь тип; работает и в режиме смешивания.
  • Кнопки смешивания — прилипающая панель у списка рта: «✚ Всё» (выделить всё для смешивания), «→ В смешение» (войти в режим, сохранив выделение), «✖ Снять».

Само смешивание скрипт не подтверждает — после выделения вы сами нажимаете игровую кнопку «Смешать».
